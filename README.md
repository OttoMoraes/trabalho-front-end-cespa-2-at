# 💙 Tela Inicial Banco do Brasil (HTML + CSS)

## 📖 Sobre o projeto

Este projeto consiste na recriação da parte superior (área azul) da tela inicial do aplicativo do Banco do Brasil utilizando apenas **HTML5** e **CSS3**.

O objetivo é praticar conceitos de desenvolvimento front-end, como posicionamento de elementos, gradientes, responsividade e organização do código.

> **Observação:** Este projeto possui apenas fins educacionais e não tem qualquer vínculo oficial com o Banco do Brasil.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Font Awesome (ícones)

---

## 📂 Estrutura do projeto

```
projeto/
│
├── index.html
├── style.css
└── README.md
```

---

## 🎨 Funcionalidades

- Fundo com gradiente azul.
- Logo posicionada no topo.
- Ícones de notificações e mensagens.
- Faixa diagonal transparente.
- Mensagem de boas-vindas.
- Card de usuário.
- Botão "Trocar conta".
- Rodapé com chamada para benefícios.

---

## 📱 Layout

O layout foi desenvolvido inspirado na tela inicial do aplicativo do Banco do Brasil, buscando uma aparência moderna e organizada.
